# SpendWiseFamily

An AI-powered MERN family expense management platform that helps families collaboratively track expenses, manage budgets, achieve savings goals, and receive smart financial insights.

## Features

### Authentication
- User registration and login
- JWT authentication
- Guest mode exploration

### Family Management
- Create family groups
- Join family groups using invite codes
- Admin and member roles

### Expense Management
- Add expenses
- Edit expenses
- Delete expenses
- Category filtering
- Admin can manage all expenses

### Budget Tracking
- Create category-wise budgets
- Progress indicators
- Remaining budget calculations

### Savings Goals
- Create savings goals
- Track progress
- Add savings contributions

### Analytics Dashboard
- Spending distribution charts
- Family spending insights
- Budget analysis

### AI Insights
- AI-powered financial recommendations
- Spending analysis
- Budget suggestions

### Other Features
- Dark mode
- Export reports
- Activity tracking
- Notifications
